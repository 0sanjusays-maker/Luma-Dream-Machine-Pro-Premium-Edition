## ⚡ Quick start (5 steps)

1. **Chehra lock** — `MASTER-SCRIPT.md` §2 se Kabir + Maa ki base photos banao (3-3 images).
2. **Luma settings** — §3: Ray2, Image-to-Video, 5 sec, 9:16, negative prompt on.
3. **Generate** — §5 ke 13 shots, har shot 3 takes (hero shots 5).
4. **Audio pehle** — §6 VO, §7 SFX + music. Dialogue Luma me **nahi**, post me.
5. **Grade + export** — §8 grade, §9 export (1080×1920, 30 fps, 14 Mbps).

---

## 🎯 Teen golden rules

1. **Luma se dialogue mat karwao** — silent visual + post me VO. Lips sync ka jhanjhat khatam.
2. **Ek shot = ek emotion = ek camera move.** Multi-action prompt me face warp hota hai.
3. **70% film aawaz hai** — Papa ki tooti hui saans aur sannata, video se zyada chubhta hai.
